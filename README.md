# Retro-Mikes Community App Store

Custom Umbrel Community App Store containing the MiningCore Live Dashboard app.

## Included apps

- `retro-mikes-miningcore-dashboard`
- `retro-mikes-fixedcoin-node`

## Add to Umbrel

In Umbrel App Store, add this repository URL as a Community App Store:

- `https://github.com/DE11469/retro-mikes-community-app-store`
